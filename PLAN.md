## 🔧 Системная проблема MPStats путей (обнаружена чат 13, 21.05.2026)

### Суть проблемы:
MPStats API возвращает товары по широкой категории, а не по конкретной нише.
Например путь `Аксессуары/Сумки и рюкзаки` даёт 4.7 млн товаров включая фены и джинсы.

### Что сделано:
- Улучшен фильтр — поиск по корням слов (морфология, первые 5 символов)
- Исправлены пути для 13 популярных ниш вручную
- Аудит топ-200 ниш — выявлено ~30 реально проблемных
